One notation for a DCB query

A query is one box: one call to the store. Its items sit inside, ORed. A chained boundary is several boxes – several calls – each waiting for the answer above it. Planned where values are still placeholders; resolved where a run supplied them.

One query, two items

SubscribeStudentToCourse · planned
query 1 call · 2 items, ORed
types CourseArchivedCourseCapacityChangedCourseDefinedStudentSubscribedToCourseStudentUnsubscribedFromCourse tags CourseId:{courseId}
OR
types StudentRegisteredStudentSubscribedToCourseStudentUnsubscribedFromCourse tags StudentId:{studentId} 
{
  "items": [
    { "types": ["CourseArchived", "CourseCapacityChanged",
                "CourseDefined", "StudentSubscribedToCourse",
                "StudentUnsubscribedFromCourse"],
      "tags": ["CourseId:{courseId}"] },
    { "types": ["StudentRegistered", "StudentSubscribedToCourse",
                "StudentUnsubscribedFromCourse"],
      "tags": ["StudentId:{studentId}"] }
  ]
}
